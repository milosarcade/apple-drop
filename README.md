# Apple Drop

A hard, old-fashioned arcade game. Drop apples down through the level,
dodge the ghosts, bounce off the green trampolines, and land one apple in
the gap in the floor to clear the level.

Play it: https://milosarcade.com/apple-drop/

## How to play

| Key | Action |
|---|---|
| Left / Right or A / D | Move the launcher |
| Space, or tap the screen | Drop an apple |
| Enter | Insert a coin: start, continue, or next level |
| Q | Give up, from the game over screen |

- You get 3 apples per coin, and there are 10 levels.
- A ghost that touches your apple eats it.
- When you run out, another coin lets you carry on from the same level.

The coins are pretend. The game just keeps count of how much you would
have fed the machine.
